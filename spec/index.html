02Wiki Conventions

  • One topic per file. Each spec page is self-contained HTML, lowercase-kebab named (providers.html, diff-ui.html).
  • Versioned core spec. The core spec is versioned (v0.html, later v1.html). Old versions are kept, never overwritten — they're the historical record.
  • Index is the hub. index.html lists every page with a status badge (Current / Draft / Planned) and links it.
  • Shared styling. Pages reuse the same inline dark theme and the sidebar/page layout so the wiki reads as one document.
  • Back-link. Every page links back to index.html.
  • Self-contained. No external assets or CDN — styles are inline so the wiki opens offline from disk.
